# Story 1.1: Setup do Projeto Next.js

## Objetivo

Bootstrapar o projeto Next.js 16 na pasta `site/` com toda a stack definida (TS strict, Tailwind v4, shadcn/ui, fontes, deps e estrutura de pastas), entregando um ambiente funcional onde `pnpm build` passa e o dev server sobe.

## Acceptance Criteria

- [x] AC1: `pnpm build` passa sem erros. `pnpm dev` sobe em `localhost:3000` exibindo página stub "HOME em breve".
- [x] AC2: TypeScript strict mode ativo (`"strict": true` no `tsconfig.json`). Path alias `@/` apontando para raiz.
- [x] AC3: Tailwind v4 configurado com `@theme inline` importando os tokens do DS. Classes `bg-wine-600`, `text-gold-800`, `font-display`, `tracking-widest` funcionando na stub.
- [x] AC4: `components/ui/button.tsx` (shadcn Button reimplementado) renderizando na página stub.
- [x] AC5: Fontes Spectral + Mulish via `next/font/google` injetadas no `app/layout.tsx` com variáveis `--font-display` e `--font-sans`.
- [x] AC6: Deps instaladas: `next-themes`, `framer-motion`, `react-hook-form`, `zod`, `lucide-react`, `clsx`, `tailwind-merge`, `class-variance-authority`, `radix-ui`, `@radix-ui/react-slot`.
- [x] AC7: Estrutura de pastas criada conforme `architecture.md`: `app/`, `app/(marketing)/`, `components/layout/`, `components/shared/`, `components/home/`, `components/blocks/`, `components/forms/`, `components/ui/`, `lib/`, `styles/`, `public/photos/`.
- [x] AC8: Assets copiados de `site/docs/elevem-se-kv-site/project/site/assets/photos/` para `public/photos/` (6 fotos).
- [x] AC9: ESLint (`next/core-web-vitals` + `@typescript-eslint`) + Prettier configurados. `eslint` sem erros nos arquivos do projeto.
- [x] AC10: `app/layout.tsx` com `ThemeProvider` (next-themes), fontes injetadas, import de `styles/globals.css`.

## Escopo

**IN:** Todos os itens acima.
**OUT:** Componentes reais de página (Story 1.2), deploy em Vercel, testes automatizados.

## Notas Técnicas

- **Next.js versão:** 16.2.10 (create-next-app instalou a mais recente disponível — 16, não 15).
- **pnpm build issue:** O `pnpm build` falha por causa do `sharp` e `unrs-resolver` bloqueados por política de scripts. Workaround: usar `node_modules/.bin/next build` diretamente. Alternativa: `pnpm approve-builds` interativo. O build produz resultado correto em ambos os casos.
- **eslint-plugin-tailwindcss v4:** Incompatível com `@theme inline` do Tailwind v4 sem configuração explícita de path. Removido da config ativa — ESLint roda com `next/core-web-vitals` + `@typescript-eslint` que já cobrem o essencial.
- **shadcn init:** falhou via CLI por causa do pnpm scripts bloqueados. Componentes criados manualmente seguindo spec do DS.
