# Story 2.3: Motion Vida + Profundidade 3D + Integração de Fotos

## Contexto
Diretor validou 2.2 com nota alta ("A capa ficou excelente. A identidade ficou muito boa"). Feedback de 7 refinos concretos para dar VIDA e SOFISTICAÇÃO:

## Acceptance Criteria

- [ ] **AC1: Palavras se construindo na tela** — todo H1/H2/H3 e leads dos blocos devem usar **SplitText / word-stagger reveal** ao entrar no viewport. Cada palavra (ou letra em títulos grandes) entra com stagger via Framer Motion ou GSAP SplitText. Não pode ficar estático. Aplica em: Prova stats, Dores título+lead, Conceito título+3 frases, MetodoResumo título, Mentores título+bio, Depoimentos título+cards, Legado frase, FinalCta título+sub. Respeita `prefers-reduced-motion`.

- [ ] **AC2: Cursor chama expandido** — o cursor com símbolo ELEVEM-SE (chama) atual continua base, mas:
  - **Rastro (trail)** — pequenas chamas menores seguindo com delay (partículas trail 200-400ms)
  - **Magnetic buttons** — CTAs "Quero aplicar" e "Conhecer o método" ATRAEM o cursor quando o mouse chega perto (efeito magnético)
  - **Hover states**: sobre CTA → chama cresce e brilha mais; sobre link nav → chama fica pequenina; sobre foto → chama vira anel dourado; sobre texto → chama vira barra fina de leitura
  - **Blend mode** mantém difference/screen dependendo do fundo

- [ ] **AC3: Cards do Método com profundidade 3D real** — os cards das fases (Fase 01 / Fase 02 / Resultado) devem ter:
  - `perspective` + `transform-style: preserve-3d`
  - Layers stackados: base + inner shadow + top highlight 1px dourado
  - Sombra multicamada: `box-shadow: 0 8px 24px rgba(42,16,22,0.06), 0 20px 60px rgba(42,16,22,0.10), inset 0 1px 0 rgba(255,255,255,0.4)`
  - Float animation sutil (translateY oscilando 6-8px em 6s)
  - Hover: cards inclinam suavemente na direção oposta ao cursor (tilt 3D)
  - Título de cada card com letra dourada MAIÚSCULA em Spectral serifada elegante
  - Bordas com 1px dourado hairline no top

- [ ] **AC4: Fotos integradas ao layout (não em quadrados)** — Aplicar em blocos que hoje têm fotos "presas em box":
  - **Dores**: foto `/photos/dores-couple-hug-bw.jpg` fica **flutuando na lateral esquerda**, com `mask-image: radial-gradient(ellipse at center, black 40%, transparent 80%)` pra fade nas bordas, drop-shadow vinho, e o **título "Vocês se amam..." fica ao lado, ocupando o espaço**. Não é foto contida — é foto "vazando" no layout.
  - **Conceito**: foto Marcela sticky lateral já usa efeito parecido; aprimore com `mask-image` fade nas bordas + drop-shadow dourada suave.
  - **Depoimentos**: cards mantêm mas os avatares dos casais viram fotos reais em círculo com ring dourado 2px + shadow. Se não houver fotos reais de casais, mantém iniciais.
  - **Mentores**: fotos individuais Marcela e Maycko podem ganhar máscara oval + drop-shadow em vez de retângulo cortado.
  - Use `mix-blend-mode: multiply` (sobre fundos claros) ou `screen` (sobre fundos dark) pra integrar fotos ao ambiente.

- [ ] **AC5: Legado — reposicionar casal pro canto** — na foto `legado-couple-white.jpg`, ajustar `objectPosition` pra alinhar o casal a um dos cantos (esquerdo ou direito), deixando pelo menos 45% do espaço horizontal LIVRE pra o texto ocupar melhor. Testar `objectPosition: '15% 30%'` ou `'85% 30%'`. O texto (eyebrow + frase + assinatura) reposicionado no espaço livre com composição balanceada.

- [ ] **AC6: "Estratégica" com E de chama** — no H2 do bloco Conceito (`Relacionamento saudável não é ausência de problemas. É construção estratégica.`), substituir a **primeira letra "E"** da palavra "estratégica" pelo **SVG do símbolo da chama ELEVEM-SE** (2 filamentos vinho + dourado). Componente: `<FlameLetter />` que renderiza inline no lugar de "e" com tamanho/altura alinhados à typografia. Deve manter kerning natural.

- [ ] **AC7: Shine effect no CTA "Quero aplicar"** — nos dois CTAs "Quero aplicar" (Hero e FinalCta):
  - Adicionar **shimmer** (feixe de luz dourado passando de esquerda pra direita) em loop de 4-6s
  - Técnica: pseudo-elemento `::before` com `background: linear-gradient(115deg, transparent 30%, rgba(255,220,150,0.5) 50%, transparent 70%)` + `background-size: 300% 100%` + animação de background-position
  - Não interferir com glow pulsante existente
  - Trigger no hover: shimmer acelera e brilha mais forte

- [ ] **AC8: Build limpo, sem quebras** — `pnpm build` e `tsc --noEmit` sem erros. Motion respeita `prefers-reduced-motion`. Responsivo mobile mantido.
