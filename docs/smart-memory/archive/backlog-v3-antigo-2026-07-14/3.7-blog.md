# Story 3.7: Nova página /blog — Placeholder Editorial Premium

## Objetivo

Criar a nova página `/blog` com layout premium e leve, exibindo 3-5 posts de curadoria inicial (fase 1: conteúdo externo de temas de casal), estruturado para expansão futura com produção própria de Maycko e Marcela.

## Acceptance Criteria

- [ ] AC1: Rota `/blog` criada e acessível
- [ ] AC2: Layout de listagem com ao menos 3-5 cards de posts (curadoria ou placeholders marcados)
- [ ] AC3: Cards com: imagem/thumbnail, categoria, título, lead breve e CTA "Ler artigo →"
- [ ] AC4: Post em destaque (featured) na abertura da página
- [ ] AC5: Filtro por categoria visualmente presente (mesmo que funcionalidade seja parcial na fase 1)
- [ ] AC6: Página `/blog/[slug]` com layout de leitura long-form para ao menos 1 post exemplo
- [ ] AC7: Barra de progresso de leitura no `blog/[slug]` (ReadingBar existente no KV)
- [ ] AC8: Nova paleta V3 (story 3.1) aplicada — layout leve, muito respiro, cards claros

## Escopo

**IN:**
- `_v3-dev/app/(marketing)/blog/page.tsx` — substituir shell de 3.0 com layout premium
- Criar `_v3-dev/app/(marketing)/blog/[slug]/page.tsx`
- Criar `_v3-dev/components/blog/` — PostCard, Featured, ReadingBar, grid
- 3-5 posts hardcoded (curadoria ou placeholders)
- Filtro por categoria (visual — sem state complexo se possível via Server Component)

**OUT:**
- Não integrar CMS nesta fase (Sanity/Contentful — decisão pendente do diretor)
- Não criar sistema de busca
- Não criar newsletter inline no blog (já existe no footer global)
- Produção própria de conteúdo é fase 2 — fora do escopo desta story

## Contexto Técnico

**Worktree:** `_v3-dev/` — todo trabalho acontece aqui. V2 permanece intacto no working tree principal.

**Shell já entregue em story 3.0** — `_v3-dev/app/(marketing)/blog/page.tsx` existe como placeholder e "Blog" já está na nav. Esta story substitui o shell com layout premium e posts iniciais.

Depende de 3.0 (shell + nav) e 3.1 (tokens V3). KV prototypes existentes: `blog.html` / `blog.jsx` e `blog-post.html` / `blog-post.jsx`.

6 posts hardcoded já existem no KV (slugs: estrutura-vs-sorte, cnpj-cpf, modo-automatico, dinheiro-a-dois, admiracao, proposito-legado). Podem ser reutilizados como base.

CMS futuro: decisão pendente do diretor (Sanity, Contentful, Notion API ou arquivo estático). Esta story deve usar arquivo estático para facilitar migração futura.

Categorias do KV: Todos, Relacionamento, Empreendedorismo, Finanças do casal, Propósito, Eventos.
