# Story 3.6: Nova página /conteudo — Ebooks, Vídeos e Podcasts Unificados

## Objetivo

Criar a nova página `/conteudo` que unifica ebooks, vídeos e podcasts em uma única experiência editorial com 3 seções ou abas, cada item como card claro com CTA específico.

## Acceptance Criteria

- [ ] AC1: Rota `/conteudo` criada e acessível
- [ ] AC2: Página estruturada em 3 seções ou abas: Ebooks · Vídeos · Podcasts
- [ ] AC3: Cada item de conteúdo é um card claro com: título, descrição breve, e CTA (baixar / assistir / ouvir)
- [ ] AC4: Vídeos e Podcasts podem coexistir na mesma seção/aba se o layout permitir (Michel confirmou)
- [ ] AC5: Nav atualizada para incluir "Conteúdo" nos links
- [ ] AC6: Página funciona com conteúdo placeholder marcado como `[PENDENTE — produção de conteúdo]` onde não houver material real
- [ ] AC7: Nova paleta V3 (story 3.1) aplicada — cards claros em fundo bege ou alternado

## Escopo

**IN:**
- `_v3-dev/app/(marketing)/conteudo/page.tsx` — substituir shell de 3.0 com conteúdo completo
- Criar `_v3-dev/components/conteudo/` com cards e estrutura de seções/abas
- Placeholder de conteúdo com ao menos 2-3 itens por seção (ebooks, vídeos, podcasts)

**OUT:**
- Não criar CMS ou backend — conteúdo hardcoded nesta fase
- Não criar players de vídeo nativos — links externos (YouTube, etc.)
- Não criar players de podcast — links externos (Spotify, etc.)
- Blog é escopo separado (story 3.7)

## Contexto Técnico

**Worktree:** `_v3-dev/` — todo trabalho acontece aqui. V2 permanece intacto no working tree principal.

**Shell já entregue em story 3.0** — `_v3-dev/app/(marketing)/conteudo/page.tsx` existe como placeholder e "Conteúdo" já está na nav. Esta story substitui o shell com conteúdo completo.

Depende de 3.0 (shell + nav) e 3.1 (tokens V3). Página nova — sem KV prototype existente para esta rota.

Componente de tabs pode reutilizar o padrão `Tabs` do `shared/blocks.jsx` ou reimplementar como Server Component simples.

Nav: "Conteúdo" já presente na posição correta pela story 3.0 — não recriar.
