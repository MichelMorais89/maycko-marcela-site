## Issues documentados

### [CONCERN-1] C1 — "crise" no Manifesto.tsx:76
- **Arquivo:** `components/home/Manifesto.tsx:76`
- **Copy:** `"não é evitar a crise."`
- **Avaliação:** uso retórico por contraste (argumento "não é X, é Y") — intenção editorial é válida. Porém o termo "crise" está explicitamente proibido pelo playbook e gate-criteria.
- **Recomendação:** substituir por formulação que não use o termo. Ex: `"não é evitar o desgaste."` ou `"não é o que você pensa."`.

### [CONCERN-2] B1 — EvolucaoSemCrise.tsx arquivo legado ativo no diretório
- **Arquivo:** `components/home/EvolucaoSemCrise.tsx`
- **Situação:** não importado na page.tsx, mas existe no diretório home. Contém "crise", "restauração", fundo escuro anchor.
- **Risco:** importação acidental ou reativação futura sem revisão.
- **Recomendação:** mover para `_archive/` ou deletar. Não manter no diretório ativo.

### [CONCERN-3] E6 — Porta do _v3-dev não configurada explicitamente
- **Arquivo:** `_v3-dev/package.json`
- **Situação:** `"dev": "next dev"` sem `-p 3002` ou equivalente.
- **Risco:** colisão com V2 (3000) se rodado em paralelo sem especificação manual.
- **Recomendação:** mudar para `"dev": "next dev -p 3002"`.

### [INFO] D5 — Label "Início" vs "Home" na nav
- Critério D5 usa "Home" como referência. Nav usa "Início" como label visual com href="/". Semanticamente equivalente. Não é FAIL nem CONCERNS — registrado como info.
