# Story 3.0: Navegação V3 + Shells das Rotas Novas

## Objetivo

Criar a nav V3 completa com as 7 abas e gerar shells (páginas placeholder) para as 3 rotas novas (Biografia, Conteúdo, Blog), para que Michel consiga navegar o mapa completo do site enquanto o refactor de cada página acontece.

## Acceptance Criteria

- [ ] AC1: `SiteNav.tsx` atualizado com ordem exata: Home · Método · Mentoria · Biografia · Conteúdo · Blog · Contato
- [ ] AC2: Shell `/biografia` — página mínima com título "Biografia" e placeholder de conteúdo
- [ ] AC3: Shell `/conteudo` — página mínima com título "Conteúdo" e placeholder de conteúdo
- [ ] AC4: Shell `/blog` — página mínima com título "Blog" e placeholder de conteúdo
- [ ] AC5: Redirect `/sobre` → `/biografia` configurado em `_v3-dev/next.config.js`
- [ ] AC6: Todas as 7 abas da nav apontam para rotas existentes — zero 404
- [ ] AC7: `next build` passa sem erro no worktree `_v3-dev/`

## Escopo

**IN:**
- `_v3-dev/components/layout/SiteNav.tsx` — atualizar `NAV_LINKS` com as 7 rotas V3
- Criar `_v3-dev/app/(marketing)/biografia/page.tsx` — shell mínimo
- Criar `_v3-dev/app/(marketing)/conteudo/page.tsx` — shell mínimo
- Criar `_v3-dev/app/(marketing)/blog/page.tsx` — shell mínimo
- `_v3-dev/next.config.js` — adicionar redirect `/sobre` → `/biografia` (permanent: true)

**OUT:**
- Não implementar conteúdo das páginas (escopo de 3.5, 3.6, 3.7)
- Não alterar paleta ou tokens (escopo de 3.1)
- Não criar `/blog/[slug]` (escopo de 3.7)
- Não alterar nav mobile além dos links

## Contexto Técnico

**Worktree:** `_v3-dev/` — porta 3002. Deve ser feita junto com 3.1 (ou antes), pois garante que dev-alpha e Michel possam navegar o mapa completo do site desde o início.

Shell mínimo = `page.tsx` com `<main><h1>Título</h1><p>[Em construção]</p></main>` — sem estilos complexos. A paleta V3 e o conteúdo chegam nas stories subsequentes.

Nav atual (V2): Home · Sobre · O Método · A Mentoria · Blog · Contato.
Nav V3: Home · Método · Mentoria · Biografia · Conteúdo · Blog · Contato.
