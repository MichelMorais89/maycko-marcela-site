# Story 3.1: Sistema de Design V3 — Nova Paleta + Tokens Tailwind

## Objetivo

Atualizar os tokens de cor e background do design system para a nova hierarquia V3 (bege dominante, vinho/navy como destaque, dourado como premium), garantindo ritmo alternado de fundos e contraste correto em todo o site — base obrigatória para todas as demais stories.

## Acceptance Criteria

- [ ] AC1: Token `--bg-base` mapeado para bege/cream como cor padrão de fundo de página
- [ ] AC2: Tokens `--section-light`, `--section-dark`, `--section-gold` criados e documentados para as variantes de seção
- [ ] AC3: Regra de contraste aplicada: seção escura → cards claros; cards escuros → fundo claro (nunca escuro-em-escuro)
- [ ] AC4: Ritmo de fundos documentado no `site.css` como comentário de padrão (claro → escuro → claro → claro+dourado)
- [ ] AC5: `_v3-dev/styles/globals.css` e `_v3-dev/styles/ds/colors.css` atualizados e buildando sem erro
- [ ] AC6: Nenhum bloco de fundo escuro consecutivo sem separação visual

## Escopo

**IN:**
- Atualizar `_v3-dev/styles/ds/colors.css` — nova hierarquia de cores
- Atualizar `_v3-dev/styles/site.css` — variantes de seção `.elv-sec--cream`, `--wine`, `--deep`, `--ink`, `--gold`
- Definir e documentar regra de contraste fundo × card
- Garantir `next build` sem erro dentro de `_v3-dev/`

**OUT:**
- Não alterar componentes de conteúdo (Hero, Dores, etc.) — isso é escopo das stories 3.2 a 3.8
- Não criar novos componentes React nesta story
- Não alterar tipografia nem spacing tokens

## Contexto Técnico

**Worktree:** `_v3-dev/` (branch nova, porta diferente — V2 permanece intacto no working tree principal).

Stack: Next.js 15, Tailwind v4 (se integrado via PostCSS), tokens CSS customizados em `_v3-dev/styles/ds/`.

Tokens atuais estão em `_v3-dev/styles/ds/colors.css`. A paleta V2 tinha vinho/navy predominantes. V3 inverte: bege é base, escuros são pontos estratégicos.

Referência: [[project/v3-briefing]] — seção "Paleta — nova hierarquia" e "Contraste dos blocos".

Esta story deve ser concluída ANTES que dev-alpha comece qualquer outra story V3.
