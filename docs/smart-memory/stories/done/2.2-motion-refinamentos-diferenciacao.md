# Story 2.2: Motion Refinamentos + Diferenciação

## Contexto
Diretor validou 2.1 ("gostei muito") mas apontou 6 refinos concretos após avaliação visual no Chrome.

## Acceptance Criteria

- [ ] AC1: **"ELEVEM-SE" em uma linha só** — ajustar tipografia responsiva do título hero (usar `text-clamp`/`text-fluid` ou clamp CSS) pra nunca quebrar em 2 linhas em nenhum viewport (375, 768, 1280, 1920+). Aplicar `whitespace-nowrap` se necessário.
- [ ] AC2: **Copy do Hero fora dos rostos** — reposicionar o bloco de texto do Hero (título + subtítulo + CTA) pra lateral esquerda (ou direita), NUNCA sobrepondo os rostos do casal na `hero-couple.jpg`. Análise: no crop atual, o casal está aproximadamente no centro da foto — mover copy pra ~30% esquerda ou direita, criar zona de respiro no rosto.
- [ ] AC3: **Cursor com símbolo da chama** — substituir o círculo vinho atual por SVG da chama ELEVEM-SE (símbolo com 2 filamentos vinho + dourado — ver `docs/elevem-se-design-system/brand-book/`). Efeito: cursor vira pequena chama animada seguindo o mouse. Manter blend-mode. Desativado em mobile.
- [ ] AC4: **Mais fotos nos blocos "lisos"** — adicionar fotos das reservas em blocos que hoje têm só texto:
  - Bloco Dores: adicionar `#57` (casal BW abraço) como imagem lateral/background
  - Bloco Conceito: adicionar `#63` (Marcela perfil dark) como foto sticky lateral
  - Bloco Depoimentos: pode adicionar `#38` (Marcela tablet) como imagem que ilustra "mentora em ação"
  - Bloco MetodoResumo: adicionar `#25` (Marcela kimono sitting) como elemento lateral flutuante
  - Copiar as fotos escolhidas de `docs/fotos-ensaio-mm/` para `public/photos/` com nomes semânticos (`dores-couple-hug-bw.jpg`, `conceito-marcela-dark.jpg`, `depoimentos-marcela-tablet.jpg`, `metodo-marcela-kimono.jpg`)
- [ ] AC5: **Transições contínuas entre blocos** — implementar 3-4 dessas técnicas (dev escolhe as que melhor encaixam):
  - **SVG path morphing** — linha dourada que atravessa vários blocos como fio narrativo
  - **Gradiente conectivo** — cor de um bloco vaza sutilmente pro início do próximo
  - **Elementos flutuantes** que aparecem no fim de um bloco e continuam no início do próximo (partícula dourada, chama, etc)
  - **Scroll-linked scene changes** — usar GSAP timeline pra encadear transições ao longo do scroll (não corte seco entre seções)
  - **Text staggering entre blocos** — última palavra de um bloco "voa" pro próximo
- [ ] AC6: **Diferenciar blocos** — cada bloco com identidade visual própria (nem todos com fundo creme uniforme):
  - Hero — foto full-bleed + aurora respirando (atual)
  - Prova — fundo escuro sutil ou textura diferente pra destacar números
  - Dores — split com foto BW + texto sobre fundo vinho profundo
  - Conceito — fundo creme + sticky foto Marcela dark
  - MetodoResumo — fundo com textura de linhas douradas (linhas SVG diagonais 3% opacidade)
  - Mentores — atual (sticky reveal está bom)
  - Depoimentos — cards mais elaborados com foto de fundo em blur
  - Legado — full-bleed atual
  - FinalCta — fundo dark com dourado forte + chama animada grande atrás do CTA
- [ ] AC7: Motion respeita `prefers-reduced-motion` em todas as novas features.
- [ ] AC8: Responsivo — em mobile, versões simplificadas (sem cursor chama, transições continuas mais leves).
- [ ] AC9: `pnpm build` limpo, `tsc --noEmit` limpo.

## Escopo

**IN:**
- Ajustes finos em componentes existentes da 2.1.
- Trocar `CustomCursor` por versão com SVG chama.
- Copiar novas fotos reservas para `public/photos/`.
- Adicionar fotos aos blocos Dores, Conceito, Depoimentos, MetodoResumo.
- Implementar transições contínuas entre blocos (SVG path + gradientes + elementos flutuantes).
- Diferenciar backgrounds dos blocos conforme AC6.

**OUT:**
- Nova estrutura de páginas ou rotas.
- Mudança de paleta ou fontes.
- Redesign do design system.
