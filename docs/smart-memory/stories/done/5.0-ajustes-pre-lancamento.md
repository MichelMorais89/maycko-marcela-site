# Story 5.0: Ajustes finais pré-lançamento MM

> Template canônico de story do team-os. Criado e validado pelo **architect** (autoridade exclusiva).
> O implementer só atualiza **Dev Agent Record**, **checkboxes de AC** e **File List** — nunca título, AC, escopo ou QA Results.

## Contexto

Após revisão pré-lançamento conduzida pela Marcela (feedback via WhatsApp, julho/2026), foram levantados ajustes de copy, dados de contato, formulário e mídia que precisam ser aplicados antes de o site ir ao ar no domínio próprio. A V3 está tecnicamente entregue (stories 4.0–4.8 done, 4.9 em QA final). Esta story consolida TODOS esses ajustes em um único ciclo de implementação, sem alterar arquitetura de rotas ou stack.

**Regras de marca inegociáveis que se aplicam a esta story:**
- Zero vocabulário de crise ("salvar / superar / restaurar / reconciliar") — a promessa é sempre construção e elevação.
- Fé implícita (sem versículo, amém ou denominação) — os textos da Marcela já respeitam isso; conferir na transcrição literal.
- Assinatura canônica "CASAMENTOS EXTRAORDINÁRIOS SÃO CONSTRUÍDOS." permanece intacta no footer; a variante "com intenção" no AC4 é complemento, não substituição global.
- Marca > Mentoria — nenhuma edição deve inverter essa hierarquia.
