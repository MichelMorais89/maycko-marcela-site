# Story 2.7: Página /resultados

## Objetivo
**A página mais importante do site.** Reposicionamento definido pelo diretor: relacionamento é emoção — vídeo e história vendem mais que argumento. O casal precisa VER transformação, não só ler.

## Acceptance Criteria

- [x] AC1: Rota `/resultados` em `app/resultados/page.tsx` (server component, SSG).
- [x] AC2: Hero — `/videos/casal-1.mp4` autoPlay muted loop full-bleed + overlay vinho + eyebrow "RESULTADOS" + H1 "CASAIS QUE DECIDIRAM CONSTRUIR JUNTOS." + sub "Aqui você vê as transformações reais." + CTA "Quero aplicar" magnetic+shimmer + scroll hint.
- [x] AC3: Bloco "Nossos números" — 4 stats grandes com CountUp: 100+ casais mentorados · 12 meses de transformação · 100% online · Brasil todo. Cada card com ícone dourado + descrição breve.
- [x] AC4: **Bloco "Casos reais" — 3 casos em formato Antes/Durante/Depois** — cada caso é um card grande vertical dividido em 3 seções:
  - **Antes** (fundo escuro sutil) — dor específica em 2-3 linhas, foto BW
  - **Durante** (fundo médio) — o processo — 3-4 marcos
  - **Depois** (fundo dourado sutil) — a transformação — 2-3 linhas + quote curto do casal
  - Nome do casal + tempo de relacionamento no topo
  - Use fotos stock (`casal-conversa-simples.jpg`, `casal-conversa-terapia.jpg`, `casal-sofa-laptop.jpg`) pra ilustrar
- [x] AC5: Bloco "Vídeos de bastidores" — grid 2x2 com 4 vídeos curtos (2 usam `/videos/casal-2.mp4` e 2 usam `/videos/casal-3-hd.mp4` com objectPosition diferentes) autoPlay muted loop com legenda embaixo:
  - "Primeira semana de mentoria"
  - "Ritual do casal"
  - "Reencontro"
  - "Legado"
- [x] AC6: Bloco "Fotos de casais reais" — mosaic grid 6-9 fotos usando stocks: `casal-sofa-laptop.jpg`, `familia-campo-crianca.jpg`, `familia-bebe-beijo.jpg`, `familia-pjs-crianca.jpg`, `casal-montanha-bw.jpg`, `casal-conversa-simples.jpg`.
- [x] AC7: Bloco "Depoimentos em texto" — 3 cards estilo Depoimentos da HOME mas mais detalhados (histórias completas de 4-5 linhas).
- [x] AC8: Bloco "Para quem é a Elevem-se?" — 2 colunas side-by-side:
  - **É para casais que:** (5 bullets check dourado) — Se amam mas perderam a conexão · Cresceram profissionalmente e querem crescer juntos · Não querem esperar uma crise para mudar · Querem construir uma família forte · Entendem que casamento também exige desenvolvimento
  - **Não é para:** (3 bullets X vinho) — Quem procura soluções rápidas · Quem acredita que apenas o outro precisa mudar · Quem não está disposto a investir tempo na relação
- [x] AC9: CTA final grande centralizado — "Sua história pode ser a próxima." + botão "Quero aplicar para a Mentoria" magnetic+shimmer.
- [x] AC10: Metadata SEO exportada + responsivo + build limpo.
