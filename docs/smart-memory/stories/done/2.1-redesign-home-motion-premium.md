# Story 2.1: Redesign HOME — Motion Premium

## Contexto
A HOME implementada na Story 1.2 ficou visualmente básica. Diretor (Michel Morais, 2026-07-08) validou 3 sites de referência pelo **motion e elaboração**:
- [erikacrivellari.com](https://www.erikacrivellari.com) — dark luxury boutique
- [craniumdigital.com.br](https://craniumdigital.com.br) — aurora animada de fundo
- [joaoguirunas.com](https://joaoguirunas.com) — dotted grid + reveal anims

**Decisão do diretor:** manter 100% identidade ELEVEM-SE (paleta creme + vinho + dourado, fontes Spectral + Mulish) — importar apenas **motion, composição e elaboração** dos sites de referência.

## Objetivo
Redesenhar a HOME com movimento cinema-grade e composição elaborada, mantendo identidade ELEVEM-SE, entregando sensação de site premium/luxury (não "landing genérica").

## Acceptance Criteria

- [ ] AC1: Identidade visual ELEVEM-SE 100% preservada — fundo creme surface-base, vinho principal, dourado acento, tokens do DS sem alteração.
- [ ] AC2: Tipografia Spectral + Mulish sem alteração — mas uso mais elaborado (títulos gigantes caixa-alta, escala tipográfica arrojada).
- [ ] AC3: **Hero cinemático** — foto `hero-couple.jpg` com parallax scroll, spotlight radial vinho seguindo cursor, partículas douradas flutuando via canvas 2D, título "ELEVEM-SE" Spectral gigante caixa-alta com cada letra caindo com stagger + mask reveal, gradient vinho→creme sobre a foto.
- [ ] AC4: **Aurora animada de fundo** — SVG blur com blobs em vinho + dourado, respirando devagar (ciclo 8-12s), presente em toda a página em opacidade sutil (não polui leitura).
- [ ] AC5: **Dotted grid vinho** 3% opacidade em toda página como padrão de fundo estático.
- [ ] AC6: **Bloco Método → horizontal snap-scroll** — as fases do método passam lateralmente ao scrollar (usando `scroll-snap-type: x mandatory` ou GSAP ScrollTrigger horizontal). Efeito wow.
- [ ] AC7: **Bloco Mentores → sticky reveal** — foto `mentor-marcela.jpg` fica sticky enquanto texto de apresentação scrola do lado; depois desliza pra foto do Maycko e reproduz o padrão.
- [ ] AC8: **Bloco Prova → counting animation** — os números escalam de 0 até o valor final quando entram no viewport (via `IntersectionObserver` ou GSAP).
- [ ] AC9: **Cards tilt 3D suave** no hover (react-tilt ou custom com CSS `perspective` + `transform: rotate3d`) + shadow dourada suave.
- [ ] AC10: **Grain film overlay** 2-3% opacidade em toda página (SVG noise ou PNG texture) — sensação cinematográfica.
- [ ] AC11: **Progress bar dourada** no topo mostrando percentual de scroll da página.
- [ ] AC12: **Lenis smooth scroll** habilitado globalmente — sensação premium de scroll.
- [ ] AC13: **Cursor customizado** — círculo vinho com blend-mode `difference` (opcional: desativado em mobile/touch).
- [ ] AC14: **CTA principal com glow vinho pulsante** + underline dos links do nav animando do centro pras bordas no hover.
- [ ] AC15: **Todos os reveals** de blocos com Framer Motion / GSAP — fade + slide + mask, respeitando `prefers-reduced-motion` (que desativa TODAS as animações complexas).
- [ ] AC16: `pnpm build` limpo, `tsc --noEmit` limpo, sem erros no browser.
- [ ] AC17: Lighthouse Performance ≥ 80 (aceito trade-off vs 90 devido ao motion pesado — sinalizar se cair mais).
- [ ] AC18: Layout responsivo em 375/768/1280 — em mobile, motion simplificado (sem cursor custom, sem parallax pesado, aurora mantida em modo lite).

## Escopo

**IN:**
- Reescrita completa dos 9 blocos + layout com o novo design + motion.
- Novos componentes: `<Aurora />`, `<DottedGrid />`, `<GrainOverlay />`, `<ScrollProgress />`, `<CustomCursor />`, `<Particles />` (canvas 2D leve), `<TiltCard />`, `<CountUp />`, `<MaskReveal />`, `<StickyReveal />`, `<HorizontalScroll />`.
- Instalar libs: `gsap` (com ScrollTrigger), `lenis`, opcional `@studio-freight/lenis-react`.
- Adaptar cada bloco existente pra usar os novos componentes de motion.
- Ajustar Hero pra ser cinematográfico (parallax + spotlight + partículas + stagger letras).
- Bloco Método reescrito como horizontal snap-scroll.
- Bloco Mentores reescrito com sticky reveal.

**OUT:**
- Mudança de paleta ou fontes.
- Reescrita do design system.
- Mudança de conteúdo/copy da HOME (usa a copy atual — se algo violar playbook, sinalizar).
- Impacto em outras páginas (ainda só HOME neste ciclo).
- Otimização extrema de performance (Lighthouse 90+ Perf — feature de história futura, se preciso).

## Contexto Técnico

- Base já entregue: Story 1.1 (setup) + Story 1.2 (HOME básica). Vamos reescrever a HOME sem re-fazer setup.
- Skills disponíveis (via team-os): `sites-scroll-motion` (padrões de scroll cinema, parallax, cenas 3D), `sites-frontend-design`, `sites-shadcn-ui`, `sites-tailwind-design-system`.
- Playbook ELEVEM-SE: `../docs/playbook-conteudo-elevem-se.md` — regras inegociáveis de marca.
- Fotos curadas em `public/photos/` — usar as mesmas 8 (documentadas em `agents/ux/curadoria-fotos-home.md`).
- Dev server ainda rodando em `localhost:3000` — Chrome auto-refresh.
- Referências pra motion: Cranium (aurora), JG (dotted grid + reveal), Erika (dark luxury boutique — mas em versão warm/creme adaptada).

## Ordem de execução recomendada

1. **Setup libs** — `pnpm add gsap lenis` + configuração base
2. **Fundo global** — Aurora + DottedGrid + GrainOverlay + ScrollProgress no `layout.tsx`
3. **Hero cinemático** — reescrever completo (parallax + spotlight + partículas + stagger)
4. **Blocos simples** — aplicar mask reveal + fade + tilt em Prova, Dores, Conceito
5. **Método horizontal scroll** — reescrever completo
6. **Mentores sticky reveal** — reescrever completo
7. **Legado + FinalCta** — aplicar reveals + parallax nas fotos
8. **Cursor custom** + micro-interações finais (CTA glow, nav underline)
9. **Responsivo mobile** — simplificar motion
10. **QA visual completo** — comparar com screens de referência do bundle KV + screenshots dos 3 sites inspiração
