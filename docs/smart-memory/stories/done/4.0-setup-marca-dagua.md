# Story 4.0: Setup Branch V3 + Elemento Gráfico ELEVEM-SE (Marca d'Água)

## Objetivo

Preparar a fundação técnica da V3 (branch `feature/v3-copy` já criada) e implementar o **elemento gráfico ELEVEM-SE como marca d'água** — a única mudança priorizada pelo diretor criativo. Sem essa peça, nenhuma das outras stories entrega o "marca > mentoria".

## Direção Criativa

> "Que cada pessoa saia do site lembrando menos da mentoria e mais da marca ELEVEM-SE."

A palavra ELEVEM-SE vira **elemento vivo de navegação** — não apenas logotipo. Presente em todos os Heros e em blocos-chave, com movimento sutil.

## Acceptance Criteria

- [x] AC1: Componente `<ElevemseWatermark />` criado, aceita props `variant` (outline · solid) · `color` (dourado · vinho) · `motion` (breathing · horizontal-slide · zoom · parallax · none) · `opacity` (default 0.05-0.10) · `size` (full · half · quarter)
- [x] AC2: SVG do texto "ELEVEM-SE" gerado com peso fino em outline, escala infinita, peso <10KB
- [x] AC3: Breathing animation implementada (scale 100% → 101% → 100%, 7s, easing suave, opacity constante)
- [x] AC4: Horizontal-slide implementada (translate-x -50% → +50% em ~40s, loop alternate)
- [x] AC5: Zoom contínuo implementado (scale 100% → 105% em 20s, alternando)
- [x] AC6: Parallax discreto implementado (deslocamento 20% do scrollY via rAF)
- [x] AC7: Todas as animações respeitam `prefers-reduced-motion` — animação desliga, marca d'água permanece estática
- [x] AC8: Marca d'água z-index=0 (atrás do conteúdo), pointer-events=none, opacidade fixa via prop
- [x] AC9: Página `/lab/marca-dagua` demonstrando 4 motions × 2 cores + variações de tamanho
- [x] AC10: `next build` passa sem erro (verificado — rota aparece na build)
