Uppercase wide-tracking eyebrow label — the small gold line of text that sits above a serif heading. Core to the editorial rhythm.

```jsx
<Badge tone="gold" rule>Mentoria para casais</Badge>
<Badge tone="onWine">Método Elevem-se</Badge>
```

- Pair every major heading with a Badge eyebrow. Keep it 1–4 words. Use `rule` for the signature gold tick. `tone="onWine"` on wine backgrounds.
