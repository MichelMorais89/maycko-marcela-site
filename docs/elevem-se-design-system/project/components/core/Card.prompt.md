Warm surface container — restrained 8px radius, hairline or soft warm shadow. The default content holder.

```jsx
<Card variant="raised" pad="lg">
  <Badge tone="gold" rule>Pilar 01</Badge>
  <h3>Verdade e bastidores</h3>
  <p>…</p>
</Card>
```

- `plain` for grids of many cards, `raised` to lift a featured one, `wine` for an emotional highlight, `ink` (navy) for a structural/authority block, `outline` for a quiet gold-framed block.
- Keep corners subtle (never fully rounded), shadows soft and warm. Don't stack heavy shadows.
