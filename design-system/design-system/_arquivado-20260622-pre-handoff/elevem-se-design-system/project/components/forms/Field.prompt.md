Form field wrapper — uppercase label, optional hint, error state. Wrap an `Input` (or any control).

```jsx
<Field label="Seu melhor e-mail" hint="Você recebe o convite por aqui." required htmlFor="email">
  <Input id="email" type="email" placeholder="nome@empresa.com" />
</Field>
```

- Keep labels short and respectful. Errors are calm and specific, never shouty.
