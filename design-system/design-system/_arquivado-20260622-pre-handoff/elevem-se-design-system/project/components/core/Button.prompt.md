Primary call-to-action. Uppercase Mulish, wide tracking, pill shape — calm and premium.

```jsx
<Button variant="primary">Quero a mentoria</Button>
<Button variant="secondary">Saber mais</Button>
<Button variant="ghost" size="sm">Voltar</Button>
<Button variant="gold" size="lg">Garantir minha vaga</Button>
```

- `primary` (solid wine) for the main action; one per view. `secondary` (gold outline) for the alternative. `ghost` for tertiary/nav. `gold` for high-emphasis offers.
- Labels short and confident, sentence intent in CAPS by the component. Avoid exclamation marks / hype.
