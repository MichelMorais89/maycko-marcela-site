The official Elevem-se logo (flame mark + Spectral wordmark + "Mentoria para casais" tagline). Use it in headers, covers, footers, and any branded surface.

```jsx
<Logo variant="lockup" tone="wine" size={96} />
<Logo variant="horizontal" tone="light" size={48} tagline={false} />
```

- `variant`: `lockup` (stacked, default), `horizontal` (mark + text inline — best for nav bars), `wordmark` (text only), `mark` (symbol only — favicon/avatar).
- `tone`: `wine` on light backgrounds, `light` on wine/graphite backgrounds.
- Keep clear space ≥ the mark's ring diameter on all sides. Never recolor the strands outside the wine/ivory pairings, never stretch, never add shadow.
