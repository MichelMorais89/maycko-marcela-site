# Elevem-se · KV Site

Bundle do KV de site do Maycko & Marcela, herdado 100% do DS Elevem-se.

## Como abrir

```
cd project/site/
python3 -m http.server
```

Abre `http://localhost:8000/manifesto.html` (ou home, metodo, mentoria, sobre, contato, blog).

## Páginas

- home · manifesto · metodo · mentoria · sobre · contato · blog · blog-post
- kv-hub · application-form

Compartilhado em `project/site/shared/` (site-kit.jsx, blocks.jsx, site.css).
DS em `project/_ds/`. Fotos em `project/site/assets/photos/`. Screens de referência em `project/screens/`.
